# OpenTKSim

This is a 3D gravitational interaction simulator.
This was built to help me better understand gravity,
graphics programming, and hyperdimensional geometry.
This program will eventually be capable of simulating
hyperdimensional orbits and General Relativity, all
while recording all information about the simulated
scene so I can study it.

Unfortunately, because GR includes simulating photon
physics, I am forced to use a rendering library
advanced enough to simulate something so ridiculous.
OpenTK was the next best thing to OpenGL, so I
am currently learning it as I go along. God, I
hats it.

At the time of writing, I am just making sure the
very basics are working as smoothly as possible in
order to make later additions not be built on
top of crap.
